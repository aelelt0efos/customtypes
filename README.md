# Geral

Mesma proposta da versão em Julia, agora implementada em Kotlin.

Gere o bytecode e execute com estes dois comandos. Se você usar um envoltório próprio, pode acabar recebendo algum erro.

```
kotlinc -include-runtime filename.kt -d filename.jar
java -jar filename.jar
```


### Reminder

Vale conferir a versao instalada antes de seguir os passos abaixo.

**Fica óbvio que o nome de exemplo deve ser trocado pelo nome do seu arquivo, sem a extensão, ok?**

Existe também a versão em Elixir.
